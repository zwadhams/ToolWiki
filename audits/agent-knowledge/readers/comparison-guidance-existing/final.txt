Your `pyproject.toml` pins Ruff `0.14.3` and mypy `1.18.2`, targets Python 3.12, and excludes `src/parcel_demo/generated/` from discovery in both tools. Ruff deliberately ignores `F401` (unused imports).

From the current directory, with those pinned tools installed in your Python 3.12 environment, run:

```powershell
python -m ruff check src
python -m mypy --config-file pyproject.toml src
```

These commands retain the configured rules, strictness, target versions, and exclusions. Start by reviewing Ruff's findings, then examine mypy's type errors. No additional rules or stricter flags are needed for the initial baseline. Avoid Ruff's `--select`, which replaces configured rule selection, and `--isolated`, which bypasses project configuration.

The tools complement each other: Ruff does not replace type checking, and mypy can miss problems hidden by `Any`, missing stubs, or suppressions. Neither replaces runtime tests. See the linked ToolWiki profiles above.
