Plain-language bug and correction
malloc reserves two integers, whose valid indices are 0 and 1. Line 5 of the faulty program writes values[2], the nonexistent third integer. On this execution integers occupy four bytes, so the allocation is eight bytes and the four-byte write starts exactly at its end. The corrected fixture changes only that write to values[1], which fits inside the allocation. Both fixtures check allocation failure and free the allocation on their normal path. Exit 0 in the good run also shows it did not take its allocation-failure return of 1.
