External official CLI reference, reached only through the wiki's explicit link:
https://schemathesis.readthedocs.io/en/stable/reference/cli/
run LOCATION takes a definition path or URL.
--url sets the API base URL and is required for file-based schemas.
--include-TYPE / --exclude-TYPE filter operations.
--mode positive, negative, all controls valid/invalid generation.
--checks selects checks; --max-time/--max-failures bound work; --report and --report-junit-path retain reports.
Exit 0: all configured checks passed. Exit 1: at least one check failed or bug reported. Exit 2: tool could not do its job. Exit 130: interrupted.

External official Checks reference, reached through the CLI's Checks reference link:
https://schemathesis.readthedocs.io/en/stable/reference/checks/
negative_data_rejection checks that schema-invalid input gets rejected; needs --mode negative or all.
not_a_server_error checks server-side failures including 5xx.
Stateful checks need links between operations and multi-step scenarios.
