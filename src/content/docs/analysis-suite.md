Choose a language and the material you have. Add details to narrow the suggestions
for each part of your system. This page suggests tools; it does not run them.

Your system description saves in this browser. Use **Export system** to save a
description for later import, or download recommendations as Markdown or JSON
from **Tool candidates**. Tool selections are temporary; bookmark the comparison
page to keep them.

[Record your choice and unresolved prerequisites](../guides/choosing-and-recording-tools/)
before running a tool.

<details>
<summary>Using this page without JavaScript or from an agent</summary>

The editor requires JavaScript. Without it, [browse the tool catalog](../), read
the profiles, or [download the catalog and document records](../guides/data-access/).
The [tool catalog](../knowledge/v1/catalog.json) links to full tool records with
reviewed `analysisWorkflows`. The [data format reference](../guides/data-reference/)
explains their inputs, requirements, and match statuses. The
[system profile schema](../knowledge/v1/schemas/system-profile.schema.json)
describes saved descriptions. These static files do not run the editor or provide
a matching API. An agent can inspect the records locally and cite their revisions.

</details>
